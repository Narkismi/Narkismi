#### Currently building: Footprint (private repo)

A web app that helps people see what information about them exists online, decide what should go, and send access and deletion requests to the right party, then follow up until the content is actually removed.

- **Stack:** Next.js, React, TypeScript, Postgres, Zod, Vitest
- **Sign-in:** passwordless, with passkeys (WebAuthn) and one-time email links
- **Privacy by design:** field-level encryption (AES-256-GCM), a tamper-evident audit log, rate limiting, and minimal data retention
- **Rules engine:** routes each request by jurisdiction and platform (GDPR, DSA, CCPA, Israeli Privacy Protection Law), with the rules kept as data rather than code
- **Bilingual:** Hebrew (RTL) and English
- **Tested:** automated tests for authentication, routing, scanning and ownership checks

The code is private while the product is in development. I'm happy to walk through it on request.
